# Student Management System

## Overview

A web-based Student Management System developed using Java and Spring Boot. It allows users to manage student records through a simple web interface.

## Features

* Add new student records
* View all student records
* Update existing student details
* Delete student records
* Store records in a database
* Web interface built using Thymeleaf

## Technologies Used

* Java
* Spring Boot
* Spring MVC
* Spring Data JPA
* Hibernate
* Thymeleaf
* H2 Database
* Maven
* HTML and CSS

## How to Run

1. Install Java and IntelliJ IDEA.
2. Open this project in IntelliJ IDEA.
3. Allow Maven to download the dependencies.
4. Run `StudentmanagementsystemApplication.java`.
5. Open `http://localhost:8080` in your browser.

## Database

This project uses the H2 database for storing student records.
